# mobile-longpress-freeze + composer-caret-jump 用户验证

## 验证说明

- 验证对象：
  1. **no-touch-drag**：修复 Android 长按侧栏会话行导致整页触摸失灵（需刷新）的问题
  2. **caret-debug**：输入框光标跳末尾问题的临时插桩（复现一次即可导出现场日志）
- 环境/前置条件：Android 手机（Chrome 内核浏览器）访问 dsh Web GUI；插件已更新（改动直接生效于 link 安装，**刷新页面即可**，无需重启 dsh）；设置 → QoL 中「禁用触摸长按拖拽」「光标跳变调试（临时）」两开关默认开启
- 验证前请先刷新一次页面，确保加载新插件代码
