# sidebar-overlay 用户验证

## 验证说明

- 验证对象：移动端 sidebar 以浮层展开，不挤压主内容区域宽度
- 环境/前置条件：手机 Chrome 访问 DSH Web GUI，`sidebar-overlay` 功能开启（默认）
