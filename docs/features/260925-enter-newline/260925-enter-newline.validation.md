# enter-newline 用户验证

## 验证说明

- 验证对象：输入框内 Enter 换行不发送（设置 → QoL → 输入与键盘 → 回车换行不发送，默认关，开启后即时生效）
- 环境/前置条件：安装 dsh-qol ≥ 本次改动版本的 dsh Web GUI；验证项 1–5 用手机/桌面浏览器均可，验证项 1–2 需中文输入法
- e2e 已覆盖（27/27 绿）：开关生效/持久化、Enter/Shift+Enter 换行不发送、IME 合成事件放行（事件层）、@ 菜单 DOM 放行（事件层）、repeat 换行、Ctrl+Enter 发送、关闭后恢复宿主行为。以下为自动化无法可靠覆盖、需真机确认的场景。
