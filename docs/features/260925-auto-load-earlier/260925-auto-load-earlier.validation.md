# 到顶自动加载更早 用户验证

## 验证说明

- 验证对象：设置 → QoL「导航与切换」组新增「到顶自动加载更早」开关（默认开）
- 环境：线上 4180 实例刷新页面后生效；需一个**更早历史未加载完**的长会话（打开时顶部能看到「加载更早」药丸按钮）

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |
| --- | --- | --- | --- | --- |
| 打开长会话（顶部有「加载更早」按钮），向上滚到最顶部并停住 | 约 150ms 后自动触发加载：更早消息前插进来，视口锚定在原来看的那条附近不跳动，顶部按钮短暂转"加载中" | | 待验证 | |
| 加载完成后停在原地不再连发 | 只触发一次；再次向上滚到新顶部才会触发下一次（单发，离开顶部重新就绪） | | 待验证 | 防连环加载 |
| 点「上一条用户消息按钮」在无用户消息的会话翻到最顶 | 翻顶后自动接力加载更早历史，用户消息行出现后再点即正常逐条回溯 | | 待验证 | 与 jump 按钮联动 |
