# 上一条用户消息按钮 用户验证

## 验证说明

- 验证对象：设置 → QoL「上一条用户消息按钮」开关（导航与切换组）；右下角"回到底部"按钮上方的新按钮
- 环境/前置条件：手机访问 dsh Web（插件 dsh-qol 已加载，刷新页面生效）；当前会话已有 ≥2 条用户消息的长对话（内容超一屏可滚动）
- 注意：改动仅在本地 lib 中，线上 4180 实例需刷新页面后生效（client bundle 按需读盘）
