# dsh-qol 发布准备 — 验证要求

日期：2026-09-17 · 交付：删除弹窗居中重锚、Tab Bar 中键关闭、项目改名 dsh-qol、发布 1.0.0

自动化已覆盖（e2e 三套全绿）：插件加载/13 属性、设置分区渲染与开关持久化、手势开合侧栏、中键关闭背景 tab（含 openTabs storage 断言）、桌面零影响。

以下场景自动化无法可靠覆盖，需实机验证：

## 1. 中键关闭（桌面浏览器，需真实鼠标）

| # | 场景 | 步骤 | 预期 |
|---|---|---|---|
| 1.1 | 中键关背景 tab | 打开 ≥2 个会话 tab，鼠标中键点击非当前 tab | 该 tab 关闭，不触发切换；无浏览器自动滚动图标出现 |
| 1.2 | 中键关当前 tab | 中键点击当前活跃 tab | 关闭并切换到上一个 tab（无剩余 tab 时进入新会话） |
| 1.3 | 左键不受影响 | 左键点击 tab | 正常切换会话 |
| 1.4 | × 按钮不受影响 | 左键点击 tab 上的 × | 正常关闭 |

## 2. 弹窗居中重锚移除（手机，≤768px）

| # | 场景 | 步骤 | 预期 |
|---|---|---|---|
| 2.1 | composer 下拉菜单 | 在有对话的会话中点开输入栏的模型/工具菜单 | 菜单在触发器上方原生弹出，不溢出屏幕，不被侧栏遮挡 |
| 2.2 | hero 态菜单 | 新会话（composer 居中）点开菜单 | 原生定位弹出（不再强制屏幕居中），可接受即可 |
| 2.3 | 设置页无回归 | 打开设置 → QoL 分区 | 13 行开关正常渲染，弹窗居中重锚行已消失 |

## 3. 改名后线上部署（需重启 dsh，另行征求同意）

| # | 场景 | 预期 |
|---|---|---|
| 3.1 | 重启后插件以新名加载 | 设置分区显示 "QoL"；localStorage 键为 dsh.qol.v1（旧键 dsh.mobile-qol.v1 被忽略，开关回到全开默认） |
| 3.2 | Tab Bar / rail / 手势 | 与改名前行为一致 |
