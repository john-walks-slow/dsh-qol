# workspace-pin 用户验证

## 验证说明

- 验证对象：工作区菜单「置顶/取消置顶」+ 行右侧图钉图标（支持多工作区置顶）
- 环境/前置条件：手机访问 dsh Web（插件 dsh-qol 已加载，含 workspace-pin 二轮版本）；≥2 个工作区（如主工作区 + 另一个测试工作区）
- 注意：改动当前仅在本地 lib 中，线上 4175 实例需刷新页面后生效（client bundle 按需读盘）
